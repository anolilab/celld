# Security

## Report a vulnerability

Report it privately through GitHub: open the Security tab of this repository,
choose **Report a vulnerability**, and describe the problem, the version or
commit, and how to reproduce it.

Do not open a public issue or pull request for a security report.

## Supported versions

This repository does not publish releases yet. The latest commit on `main` is
the supported version. Once releases exist, the latest release joins it.

See [security](docs/security.md) for the threat model and the limits that apply
before you operate a public fleet.
